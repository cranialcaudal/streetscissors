# Fonts for ImageMagick

`Web.ShareCard` sets a post's title in these when it draws the picture a
shared link unfurls with, and `Web.Cuts.Titles` sets a cut's titles in them.
They are two of the faces the site itself is set in. The browser gets its
copies from the site (`priv/static/fonts/`, `assets/css/fonts.css`), never from
Google; ImageMagick needs these as plain font files.

- **Sorts Mill Goudy** (Regular), by Barry Schwartz: `SortsMillGoudy-Regular.ttf`,
  licence `SortsMillGoudy-OFL.txt`.
- **IBM Plex Mono** (Medium), by IBM: `IBMPlexMono-Medium.ttf`, licence
  `IBMPlexMono-OFL.txt`.

Both are under the SIL Open Font License 1.1, which allows bundling them with
software as long as the license travels with them. They are unmodified, from
<https://github.com/google/fonts>.
