# Fonts for the share cards

`Web.ShareCard` sets a post's title in these when it draws the picture a
shared link unfurls with. They are the same two faces the site itself is set
in, which the browser gets from Google Fonts; ImageMagick needs them as files.

- **Sorts Mill Goudy** (Regular), by Barry Schwartz. `SortsMillGoudy-OFL.txt`.
- **IBM Plex Mono** (Medium), by IBM. `IBMPlexMono-OFL.txt`.

Both are under the SIL Open Font License 1.1, which allows bundling them with
software as long as the license travels with them. They are unmodified, from
<https://github.com/google/fonts>.
